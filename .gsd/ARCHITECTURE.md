## Data Flow

1. **User Input:** User dictates a workflow via `NlInputPanel.tsx` in the frontend.
2. **API Request:** Frontend calls `POST /api/parse` via `lib/api.ts`.
3. **NLP Processing:** Backend `nlp/parser.py` uses LLM APIs to construct a node graph.
4. **State Update:** Frontend receives the graph, rendering it via `@xyflow/react`.
5. **Persistence:** User saves the workflow, writing to Supabase via `api/routes/workflows.py`.
6. **Execution:** On trigger, `services/flow_executor.py` runs the workflow step-by-step using secure credentials extracted by `integration_service.py` via `security.py`.
