## Overview

**FlowAI** is an AI-powered workflow automation platform. Users describe workflows in natural language, which an NLP parser converts into structured definitions (trigger → conditions → actions). A visual React Flow editor renders the workflow as a node graph. The backend executes actions (HTTP, Slack, Discord) on schedule or manual trigger.

## Data Flow

1. **User types NL prompt** → Frontend sends POST `/api/parse`
2. **Parser converts text** → regex detects trigger type, conditions, actions → returns `WorkflowDefinition`
3. **Frontend renders** → React Flow visualizes trigger → condition → action nodes
4. **User saves workflow** → POST `/api/workflows` stores definition + metadata in Supabase
5. **User activates** → POST `/api/workflows/:id/activate` adds APScheduler cron job (if schedule trigger)
6. **Scheduler fires** → `WorkflowRunner.run()` dispatches HTTP/Slack/Discord actions
7. **Results logged** → `log_service.create_log()` writes to `execution_logs` table
8. **User views logs** → GET `/api/logs` returns execution history

## Technical Debt

- [ ] **Email action not implemented** — `runner_service.py` raises `NotImplementedError` for email actions
- [ ] **Placeholder webhook URLs** — NLP parser outputs `PASTE_YOUR_SLACK_WEBHOOK_URL` / `PASTE_YOUR_DISCORD_WEBHOOK_URL`
- [ ] **No tests** — Zero unit/integration tests across entire codebase
- [ ] **No input validation on NL parser** — Empty strings, very long inputs, injection not handled
- [ ] **Hardcoded Supabase credentials** — `config.py` has default values (should be env-only)
- [ ] **Frontend pages are static shells** — UI exists but most pages don't call backend APIs yet
- [ ] **No error boundaries** — React app has no ErrorBoundary components
- [ ] **No rate limiting** — API endpoints have no throttling

## Conventions

**Naming:** snake_case (Python), PascalCase components (React), camelCase functions (TypeScript)
**Structure:** Feature-grouped (routes, services, schemas, models on backend; pages, components, context on frontend)
**Auth:** Bearer JWT from Supabase Auth → `get_current_user` dependency on every protected route
**State:** No client-side state management lib — useState/useContext only
**Styling:** Tailwind CSS v4 with dark theme (purple accent palette)
