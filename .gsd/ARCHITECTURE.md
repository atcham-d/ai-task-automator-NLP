## Overview

FlowAI is a low-code automation platform that uses NLP to build and execute workflows. It features a React-based frontend for workflow design and a FastAPI backend for NLP parsing, workflow scheduling, and integration management.

## Components

### Frontend (User Interface)
- **Purpose:** Provide a visual interface for managing workflows and integrations.
- **Location:** `frontend/src/`
- **Key Modules:**
  - `pages/WorkflowBuilder.tsx`: Visual editor using React Flow (@xyflow/react).
  - `context/AuthContext.tsx`: Manages user sessions and auth bypass.
  - `lib/api.ts`: Centralized fetch wrapper for backend communication.

### Backend (Logic & Execution)
- **Purpose:** Process natural language, schedule tasks, and manage data.
- **Location:** `backend/app/`
- **Key Modules:**
  - `nlp/parser.py`: Translates text into workflow nodes/edges.
  - `services/integration_service.py`: CRUD for integrations with field-level encryption.
  - `scheduler/scheduler.py`: Handles periodic triggers using APScheduler.

### Database (Storage)
- **Purpose:** Persist workflows, logs, and user metadata.
- **Location:** Managed via Supabase.
- **Tables:** `workflows`, `integrations`, `execution_logs`, `profiles`.

## Data Flow

1. **Workflow Creation**: User types NLP prompt → `WorkflowBuilder` calls `/api/parse` → Backend returns JSON → `react-flow` renders graph.
2. **Auth Flow**: User logs in → `AuthContext` calls `/api/auth/login` → Backend validates with Supabase → Frontend stores session.
3. **Execution**: Scheduler fires → `RunnerService` executes action (Slack/Discord/SMTP) → `LogService` records result.
