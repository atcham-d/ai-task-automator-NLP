## Lessons Learned
- **CORS vs. Serialization**: Internal backend serialization errors (missing fields) can present as CORS failures in the browser, making logs essential for diagnosis.
- **MacOS Loopback**: Consistency between `localhost` and `127.0.0.1` is critical on MacOS to avoid IPv6/IPv4 mismatches during fetch.
- **Dynamic Zod Rendering**: Using Zod schemas as the source of truth for UI form generation significantly reduces duplication when handling diverse integration types.
